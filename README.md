# SOC Security Threat Analysis Tool

A Python-based security script designed to analyze system logs, detect critical threats like Brute-Force attacks, and generate automated risk reports (`.csv`).

## Features
- Analyzes login logs to track failed attempts.
- Detects critical brute-force threats targeting administrative accounts (`root`, `admin`).
- Automatically generates high-risk IP reports in CSV format.
